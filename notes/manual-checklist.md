# 实机检查清单

发版前，开发者本人拿最终候选包在真实的 Chrome 里走一遍。规矩见 [PRD](product-prd.md) 第 8.3 节：一个个打开、看页面，不用脚本遍历。

首发前只走「必看」的那些步骤（开发者本人 2026-11-20 定），其余各步有空再看。

- 用最终候选包解压出来的文件夹，不用开发构建，也不用日用包。可以分几次跑，都用同一个候选包；换了候选包，受影响的节重跑。
- 单开一个 Chrome 配置，不和日用的简幕装在一起。
- 每步写的是做什么、应该看到什么。和预期不一样的，记下步骤编号和现象，接着往下走。
- 遇到限流或人机验证，整轮立即停下，没跑的记「未覆盖」，隔天再接着跑。
- 样本只按类别挑，样本清单和记录留在私有侧，不进这个仓库。
- 标「仅在进包时」的节和步骤，只在候选包带着这项功能时跑；没带就整节记「未覆盖」，写明没进包。

## 必看的步骤

这些只有在真实环境里才看得出，日用里又碰不到或者一直没核对过：全新安装、两站主流程各一遍、付费视频不读、换视频以后结果不串、打开就出结论、换 AI 服务地址后旧授权收回、升级路径、「关于」一节。

- 第 0 节：0.1 到 0.5
- 第 1 节：1.1 到 1.4、1.6
- 第 2 节：2.1、2.2、2.4、2.12，YouTube 走 2.16
- 第 4 节：4.1、4.3、4.7、4.10
- 第 6 节：6.8
- 第 8 节：8.1 到 8.4
- 第 10 节：10.5

没走的步骤照实记：日用里天天在看的记「日用里见过」，别的记「未覆盖」，不记成通过。

## 0. 准备和记录

0.1 用 `shasum -a 256` 核对候选 zip，和同名 `.sha256` 一致。
0.2 解压到一个新的固定文件夹，`manifest.json` 直接在里面。
0.3 新建一个 Chrome 配置，除第 12 节要用的沉浸式翻译外不装别的扩展。不登录 Chrome 同步，免得把别的扩展同步进来；Chrome 给新配置自带的扩展（比如 Google 文档的离线版）先停用。
0.4 记下提交号、校验值、`chrome://version` 的版本、系统版本、候选包带了哪些功能（YouTube、代开文字稿、解释当前画面）。
0.5 在这个配置里登录 B 站和 YouTube 的测试账号。准备一份能用的国内服务密钥和一份海外服务密钥。

## 1. 安装和首次启用

1.1 照 README「安装」走：开发者模式，加载已解压的扩展程序，选 0.2 的文件夹。应该装上，没有报错，不自动打开别的页面。
1.2 先不启用，打开一个 B 站视频页。应该没有卡片、没有播放器上的图标。
1.3 点工具栏图标打开侧边栏。应该先看到启用说明，写着读什么、做什么用、本机存什么。
1.4 点「启用简幕」。侧边栏换成这个视频的内容，视频页上出现卡片（没出现就刷新一次）。
1.5 打开设置页。应该看得到外观、播放页、AI 服务、打开就出结论、速读和精读、学习资料、稍后再看粗筛、关于这些节。
1.6 看设置页「关于」一节：版本号和构建标识和候选包一致（构建标识对包里的 `build-id.txt`），点「更新记录」「源码」「隐私政策」「反馈问题」四个链接都在新标签页打得开。
1.7 右键点工具栏图标。菜单里有「稍后再看粗筛」「在视频右侧显示总结卡片」「打开视频就出结论（花 API 额度）」三项。

## 2. 两站单视频主流程

先在设置页选好服务、填密钥、勾选数据说明，点「保存」。每类样本都看一遍，失败的提示要能分清是哪种原因。

2.1 B 站，有人工字幕的长视频：侧边栏读到字幕，标签写着字幕语言：自动生成的标着「自动生成」，人工上传的只写语言。速读里有官方总结（有的话）。
2.2 同一个视频点「生成概览」：章节逐块出现（字幕长到要分段时），最后有一两句话的结论，星级旁写着短词，信息不足时只写短词，标出依据，重点章节有标记。
2.3 点章节的时间点：播放器跳过去。展开一章能读这一段字幕。
2.4 提一个字幕里答得出的问题：回答带时间点和原文，点了跳回。再问一个答不出的：如实说找不到依据。
2.5 切到精读：当前章节和句子跟着播放高亮，「回到当前句」能用。
2.6 选中一句字幕点「解释」：给出结合前后文的说明。
2.7 鼠标移到播放器上出现笔记图标，点一下或按 `n`：记下这一刻和字幕。导出 Markdown 和学习稿，打开看内容对得上。
2.8 B 站，只有 AI 字幕的视频：照样读到，来源标对，判定不了时标「未确认」。
2.9 B 站，外语视频：点翻译，后台译完，关掉侧边栏再打开能接上进度；原文、译文、双语三种显示都对，导出 SRT 时间轴对得上。
2.10 没有标点的字幕点「整理字幕」：分批补上标点，能停止，能切回原始字幕。
2.11 B 站，没有字幕的视频：提示没有字幕，给导入字幕的入口。导入一份自己做的 SRT，能生成概览。
2.12 B 站，付费或充电专属视频：不读字幕，提示说清原因。
2.13 B 站退出登录后打开视频：只显示标题、时长这些信息，提示登录或导入字幕。看完重新登录。
2.14 不到 5 分钟的短视频：直接进精读，不主动给概览。
2.15 多分 P 的视频：换一个分 P，侧边栏和卡片换成这个分 P 的内容。
2.16 YouTube（仅在进包时），有人工字幕的长视频：照 2.1 到 2.7 走一遍，结论和章节用设置里选的语言（默认跟随浏览器），外文视频也一样，问答和笔记能用。
2.17 YouTube（仅在进包时），只有自动生成字幕的视频：读到的那条标成自动生成，认不出就标「未确认」。
2.18 YouTube（仅在进包时），没有字幕的视频：提示没有字幕，和读取失败的提示分得开。

## 3. B 站页面

3.1 普通播放页：卡片在右栏，位置对，不挡视频和弹幕列表。
3.2 列表播放页：在列表里换下一个视频，卡片和侧边栏跟着换。
3.3 宽屏、网页全屏各切一次：卡片挪到对应位置或让开，切回来恢复，播放不受影响。
3.4 往下滚到出现小窗播放：卡片和笔记图标不乱跑，滚回来正常。
3.5 打开一位关注过的 UP 主的主页：不出卡片和图标，侧边栏说这不是视频页。从这里点进视频，卡片的位置和展开状态都对。
3.6 滚到评论区，在评论框里打字，包括字母 `n`：不记笔记，不抢焦点，评论区照常加载。
3.7 卡片随模式：侧边栏关着时，速读里展开，精读里收成一行，短视频默认收起。
3.8 收起的那一行写着星级、短词和一句话结论；只有章节时写播放到的章节。侧边栏关着时，旁边有打开侧边栏的入口，点了打开侧边栏。
3.9 长视频在速读里连续播满 1 分钟：自动切到精读，卡片不收起。侧边栏顶上的「已切到精读」点一下能回到速读。
3.10 打开侧边栏：卡片让位收起，没有打开侧边栏的入口；关上侧边栏，卡片回来。
3.11 手动展开或收起卡片以后：这个视频里一直按手动的来，换下一个视频才恢复。
3.12 章节多于 5 章的视频：卡片只露前 5 章，点「展开全部」才全露。
3.13 在后台标签页打开一个视频：切过去之前不读，切过去以后才出卡片内容。
3.14 侧边栏开着、在速读里展开一章看要点，长视频连续播满 1 分钟：不切，展开的那章还在。关上侧边栏再播十几秒，重新打开就是精读，顶上有「已切到精读」。

## 4. YouTube（仅在进包时）

4.1 打开 YouTube 观看页，侧边栏有「在 YouTube 上启用」。点了弹出授权框，允许后不用刷新就能用。
4.2 自己先点开视频简介里的文字稿面板，再在侧边栏点「读取字幕」：读到完整正文，时间轴对得上。
4.3 代开文字稿（进包时）：不开面板直接点「读取字幕」。简幕替你点开面板读完，面板留着不关。
4.4 代开文字稿（进包时）：面板开着但停在章节页签，点「读取字幕」，切到文字稿页签读完，不关面板。
4.5 代开文字稿（进包时）：正在播广告时、面板搜索框里有字时点读取，不点面板，提示原因。
4.6 卡片上点「生成概览」：替你点开文字稿读完、生成概览，读完把面板关上。
4.7 读完核对播放器没变：播放进度、倍速、字幕开关、字幕语言、画质都和读之前一样，没有多出机器翻译的字幕。
4.8 字幕标出的语言和来源和文字稿显示的那一条一致。
4.9 卡片插在右栏推荐视频上面；文字稿面板开着时排在面板下面。剧场模式、全屏各切一次，卡片不挡视频。
4.10 在站内点推荐视频换视频：侧边栏和卡片换成新视频，旧视频的结果不留。
4.11 鼠标移到播放器上出现笔记图标；在页面上按 `n`，和 YouTube 自己的快捷键不冲突。
4.12 遇到限流或要登录的提示：简幕停下，提示说清原因，不反复试。
4.13 找一个页面上没有文字稿、播放器里有字幕的视频，字幕先关着，点「读取字幕」：简幕替你打开字幕、读完关上，读到完整正文；侧边栏标出的语言和播放器显示的那一条一致，认不出时标「未确认」。字幕本来开着的，读完照旧开着。

## 5. 身份

5.1 B 站和 YouTube（进包时）各开一个视频标签页，来回切：侧边栏跟着当前标签页，内容不串。
5.2 一个视频正在生成概览时，在站内快速连点三个推荐视频：最后停下的视频上没有别的视频的章节和结论。
5.3 用浏览器的后退、前进在几个视频间来回：每次显示的都是当前视频的内容。
5.4 生成中切到别的标签页再切回来：进度接得上，别的视频上看不到这个进度。
5.5 先开着几个 B 站视频页，再在 `chrome://extensions` 停用并重新启用简幕：这些页面上卡片补上，或者提示刷新；刷新以后正常。

## 6. 权限

6.1 `chrome://extensions` 的详情里，B 站是装好就授权的；YouTube（进包时）在启用之前没有授权。
6.2 YouTube（进包时）授权框点拒绝：提示没有授权，YouTube 上暂时用不了，B 站不受影响。
6.3 YouTube（进包时）在设置页点「停用」：已开的 YouTube 页面上简幕撤下，笔记和概览还在。
6.4 在扩展详情里手动收回一个站点的访问权限：那个站点已开的页面撤掉界面，不再读取。
6.5 停用简幕再启用：资料都在，各站授权和停用前一样。
6.6 关掉浏览器重开：已启用的状态和站点授权都在，卡片照常出现。
6.7 在设置页改 AI 设置再点「保存」：只为新的服务地址弹授权，YouTube 的站点授权不受影响。
6.8 把 AI 服务地址换成另一家再保存：新地址的授权在，B 站和 YouTube 的不变，旧地址简幕自己收回了。扩展详情的网站访问权限里旧地址还会列着：扩展自己收回的授权浏览器还记着，再申请时不弹框，所以要在扩展管理页点简幕的 Service Worker 打开控制台，跑 `chrome.permissions.getAll()`，看 origins 里没有旧地址。

## 7. 两次浏览器会话和密钥

7.1 默认不勾「在这台电脑上记住密钥」，保存后能用；按钮下面问「要把密钥记在这台电脑上吗？」，「记住」「不用」两个按钮一样分量，点「不用」收起。关掉浏览器重开，提示要重新填密钥，资料都在；重新填好保存，不再问。
7.2 勾上记住密钥再点保存，或者在保存后那一问里点「记住」：关掉浏览器重开，不用重填就能用。
7.3 取消勾选记住密钥：这次会话照样能用；关掉浏览器重开，要重新填。
7.4 点「清除密钥」：会话里的和本机记住的都清掉，记住的勾选跟着取消；再填一把保存，又会问一次要不要记住。
7.5 换一个服务商，保存：原来的密钥被移除，记住开关关掉，要填新的。
7.6 在 Chrome 140 以下的版本里勾选记住密钥再保存：明确报错，这次保存不生效，原来会话里的密钥还能用。

## 8. 升级路径

8.1 用 `npm run release -- upgrade-test` 打一个同一份代码、换了版本号和构建标识的包，照 README「更新」把文件覆盖到 0.2 的文件夹，不移除扩展。
8.2 不做别的：下一次用到时简幕自己重新加载；开着的侧边栏和设置页关掉，再打开就是新版本号。
8.3 有概览在生成时覆盖：等它做完才重新加载，结果不丢。
8.4 笔记、概览、问答、设置、启用状态和站点授权都在；没记住密钥的要重新填。
8.5 已开的视频页上卡片照常出现，或提示刷新；刷新以后正常。

## 9. 模型

9.1 点「国内服务」快捷预设，填密钥，测试连接，生成一次概览：正常。
9.2 点「海外服务」快捷预设，同样走一遍：正常。
9.3 推理强度给同一项功能分别选关、低、中、高，各生成一次：都能出结果，档越高越慢；做不到的档在旁边标出实际用的那一档。
9.4 每次之后看推理强度那一节的用量行：写着输入、输出和思考的 token 数，还有当时的档位。
9.5 故意填错密钥再生成：报错写清原因、影响、下一步，不附服务的原话。

## 10. 批量和自动

10.1 一个窗口开四五个视频，其中一个已有概览，点「本窗口全部生成」：确认数量和跳过数对得上，确认后逐个生成。
10.2 生成中点「全部停止」：不再开新的，已完成的留着。
10.3 右键菜单打开「稍后再看粗筛」：读取列表，读完直接出现第一步的确认，取官方总结，第二步写结论。「全部」里视频的顺序和稍后再看一致；筛选按钮从 5 星排到 1 星，之后是「还没判断」和「信息不足」。导出的清单也按这个顺序分组；B 站上的稍后再看列表没被改动。
10.4 没同意数据说明时，从右键菜单勾「打开视频就出结论（花 API 额度）」：不改设置，打开设置页并停在「打开就出结论」那一节。
10.5 同意以后打开这个开关，打开一个超过设定时长的视频：不用点就生成，结论显示在卡片上；外文视频不自动翻译。
10.6 打开一个没到设定时长的视频：不自动生成。
10.7 一次在后台打开好几个长视频：排队生成，正在看的先生成，同时最多两个；切过去时直接显示结论。
10.8 YouTube（进包时）在开关开着时打开长视频：替你点开文字稿读完、生成，读完把面板关上。

## 11. 外观和图标

11.1 五套主题各切一次浅色和深色，检查卡片、侧边栏和粗筛页的实心星、空心星和短词能否看清。「看不看」主题里，4 到 5 星共用一条色带，1 到 2 星共用一条，3 星和信息不足各有自己的色带。切换三档字号，侧边栏、设置页和卡片都跟着变。
11.2 明暗选「跟随系统」，切换系统的浅色、深色：跟着变。卡片的明暗跟着视频页，不跟这个设置。
11.3 把侧边栏拖到最窄：没有横向滚动条，按钮和文字不被截断。
11.4 工具栏和扩展管理页上的图标：16 像素下清楚，浅色和深色工具栏上都看得出。
11.5 只用键盘在侧边栏和设置页里走一遍：焦点看得见，主要按钮都按得到。

## 12. 共存

12.1 装上沉浸式翻译，两个都开着，打开 B 站视频：卡片、笔记图标、侧边栏照常，页面不明显变卡。
12.2 让沉浸式翻译翻译页面和字幕：简幕读到的仍是平台字幕，卡片不被它翻译坏。
12.3 YouTube（进包时）同样看一遍。

## 13. 资料

13.1 在本机用自己的旧备份恢复一次：只看导入结果（条数、有没有报错），备份文件和截图都不外传。
13.2 点「导出备份」：得到 JSON 文件，里面没有密钥。
13.3 点「清除缓存」：笔记、概览、问答和设置都还在。
13.4 点「清除全部数据」：再打开侧边栏回到启用说明，要重新启用、重新填密钥、重新同意数据说明。

## 14. 解释当前画面（仅在进包时）

挑有幻灯片、公式、代码或图表的视频。

14.1 鼠标移到播放器上，点解释画面的图标：侧边栏打开，给出结合这一帧和前后字幕的解释。
14.2 暂停、播放中、刚拖动完、缓冲中各试一次：截到的是当前这一帧，不是黑帧或旧帧。
14.3 宽屏、网页全屏、全屏、小窗、画中画各试一次：能截，或者说清为什么不截。
14.4 弹幕和控制栏开着时截：只截视频本身。
14.5 正在播广告、标签页不在前台、刚在站内换了视频：不截不发，说明原因。
14.6 模型不能看图时：提示换能看图的模型。看一下国内预设的默认模型能不能看图。
14.7 YouTube（进包时）同样走 14.1、14.2、14.5。

## 15. 繁体中文

在设置页「外观」一节把语言选「繁體中文」，用真实的模型走一遍。这些只有真实模型的输出才看得出。

15.1 B 站上一个简体字幕的视频，提几个问题：回答是繁体，出处里的原文还是字幕里的简体原文，点了跳得到；回答没有被整条换成「未能從字幕中找到足夠的根據」的兜底。
15.2 同一个视频生成概览：结论的星数旁显示繁体短词，信息不足时只有文字。读屏能一次读出星数和短词，粗筛的分组和星数也对得上。
15.3 金句是繁体：字幕是简体时只换了字形，用词还是说话人的原话；外文视频的金句译成了通顺的繁体。
15.4 中文标题的视频（简体标题也算）：侧边栏顶上照旧显示原标题，不出一个只是转成繁体的「译名」；外文标题的视频，译名是自然的繁体。
15.5 章节、摘要、问答和划词解释读下来用词是台湾的习惯（影片、資訊、軟體这类）；人名、地名和品牌照字幕里的叫法只换字形，没有被换成台湾的另一种译名。
15.6 翻译：英文、日文字幕各译一次，都译成繁体；中文字幕（简体）译成英文。
15.7 浏览器界面语言设成中文（台湾）、语言选「跟随浏览器」：界面是繁体；扩展管理页上简幕的名称和简介是繁体。

## 16. 失败记录

16.1 每个失败记下步骤编号、现象、截图在本机的位置，判断是包里的问题、包外的问题、平台变化还是网络。
16.2 包里的问题修好后打新候选，受影响的节在新候选上重跑，记录跟着新候选走。
16.3 没跑的步骤记「未覆盖」，写明为什么没跑、打算怎么补。
